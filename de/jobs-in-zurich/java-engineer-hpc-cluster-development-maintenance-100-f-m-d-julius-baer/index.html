Vollständige Beschreibung

Bei Julius Bär feiern und schätzen wir die individuellen Qualitäten, die Sie mitbringen, damit Sie wirkungsvoll sein, unternehmerisch handeln, gestärkt werden und Werte jenseits von Wohlstand schaffen können. Gestalten wir gemeinsam die Zukunft des Wealth Managements.

Schließen Sie sich uns als Java Engineer an und spielen Sie eine Schlüsselrolle bei der Weiterentwicklung unserer High-Performance Computing (HPC) Infrastruktur. Unsere hybride Plattform, die Hunderte von lokalen Servern und Cloud-Ressourcen in Microsoft Azure umfasst, bietet die leistungsstarken, belastbaren Rechenfunktionen, die eine hochmoderne Handelsplattform unterstützen. Sie werden maßgeblich an der Aufrechterhaltung, Optimierung und Skalierung dieses kritischen Umfelds beteiligt sein, während wir weiter wachsen und innovativ sind.

Die Clusterplanungs- und Steuerungssysteme sind in erster Linie in Java aufgebaut, wobei Apache Ignite als Clustering-Schicht dient. Jobs werden von internen Clients über alte HTTP- und ActiveMQ-Schnittstellen erhalten, während moderne Clients eine interne API verwenden, die in Java und Python entwickelt wurde. Systemstatistiken werden in MongoDB und Elastic/Kibana gesammelt.

Diese Rolle erfordert die Gewährleistung einer hohen Verfügbarkeit für eine unternehmenskritische Ressource, die Entwicklung eines tiefen Verständnisses einer großen vorhandenen Codebasis und Vorschläge für Verbesserungen. Sie werden auch mehrere Überwachungssysteme sowohl für die Infrastruktur als auch für die Einreichung von Kundenaufträgen pflegen und verbessern.
