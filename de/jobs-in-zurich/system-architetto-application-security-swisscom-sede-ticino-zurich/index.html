  • Erfahrung in der Implementierung von Sicherheitskontrollen zur Gewährleistung einer ganzheitlichen Systemsicherheit und Zuverlässigkeit, beispielsweise in den Bereichen Security & Infrastructure as Code, Identity & Access Management (IAM), Key Management Systems (KMS), Security Monitoring und Auditing
