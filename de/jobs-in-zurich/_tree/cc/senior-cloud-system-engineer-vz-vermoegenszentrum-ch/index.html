Das VZ ist der führende unabhängige Finanzdienstleister der Schweiz. Wir beraten Privatpersonen und Firmen zu allen Themen rund ums Geld, verwalten Vermögen und bieten attraktive Finanzdienstleistungen an. Da wir kräftig wachsen, suchen wir Verstärkung für unser IT-Team an unserem Hauptsitz beim Paradeplatz in Zürich.

  • Mitarbeit und technische Führung von Projekten sowie zur Weiterentwicklung der Azure Cloud Plattform.
  • Design und Implementierung von Cloud-Lösungen sowie Verwaltung von Services wie Azure Kubernetes Service (AKS), Azure Container Apps, Azure Application Gateway, Azure API Management mit Terraform (IaC) und Azure CLI.
  • Du verantwortest und realisierst Anforderungen von Azure Kubernetes, Policies, IAM, TerraForm (IaC), Azure DevOps und CI/CD Pipelines.
  • Du coachst und unterstützt Fachbereiche bei der Nutzung der Azure Technologien, der Entwicklung von Azure-native Anwendungen und deren Security Themen.
  • Mitverantwortung für den Betrieb der Azure Infrastruktur.
