Zuständigkeiten

  • Entwicklung universeller Vektordarstellungen (Embeddings) von Produkten und verwandten Artikeln, wie Abfragen, Marken und Kategorien.
  • Bauen Sie Zwei-Turm (Dual-Encoder) Transformermodelle, die Abfragen und Produkte in einem Vektorraum platzieren, wobei ein gemeinsamer Encoder verwendet wird, der von einem vortrainierten Gemini-Modell ausgeht.
  • Trainieren Sie Modelle mit umfangreichen Datensätzen unter Verwendung von Benutzerklicks und Relevanzetiketten, die aus einem größeren Modell abgeleitet wurden.
  • Führen Sie Schulungen auf gemeinsam genutzter Gemini-Infrastruktur aus, codieren Sie Online-Abfragen mit geringer Latenz, während Sie Produktlisten offline einbetten und indizieren, um eine schnelle Nachbarschaftsvektorsuche im Backend der Einkaufssuche durchzuführen.
  • Optimieren Sie multimodale Gemini-Einbettungsmodelle, die Produktminiaturansichten zusammen mit Titeln und Beschreibungen codieren, um den Rückruf zu verbessern.
